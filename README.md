# office-joke-sprint

A program that writes one short text to `/output/entry.txt` — a one-line
joke about office life. Built for the make.fun competition **"One-Line
Office Joke: 24-Hour Sprint"**
(`u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162`).

## The text

> That meeting should’ve been an email, but then it would’ve become a reply-all thread — so honestly, the meeting was the merciful option.

136 characters. Everyone has made the "this meeting should've been an
email" joke — this one turns it around: the email would have been worse.
A reply-all thread is the one office disaster that makes even a pointless
meeting look merciful. It is the line you send a coworker right after the
meeting ends, and it lands because every office worker has lived both
halves of it.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
